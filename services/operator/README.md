# Рабочее место специалиста (демонстрация)

Экран показывает открытые синтетические обращения, рекомендованную категорию и похожие закрытые заявки. На основе текста прежнего решения готовится черновик. Специалист редактирует его и сохраняет решение «согласовать» или «отклонить». Отправка заявителю не реализована.

После обучения поиск использует небольшую полносвязную нейронную сеть. Она получает символьные признаки темы и учится различать 15 типов синтетических проблем. Скрытый слой сети служит представлением текста для сортировки закрытых заявок. При отсутствии обученной модели остаётся поиск по совпадению слов. Оценка сходства не является вероятностью правильного решения. Тексты решений в имитаторе синтетические и шаблонные.

После полной загрузки данных соберите контейнер командой `docker compose --profile operator build operator` и обучите модель командой `docker compose --profile operator run --rm operator python train_neural.py`. Затем запустите экран командой `docker compose --profile operator up -d --build operator` и откройте `http://localhost:8502`. Для подключения нужны переменные окружения `POSTGRES_HOST`, `POSTGRES_PORT`, `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD`. Настройки и пароль не записываются в коде. Веса сети и показатели качества сохраняются локально в `artifacts/neural_model` и не попадают в Git.

Обучение использует 15 различных тем закрытых заявок и синтетические перефразировки. Разные формулировки одной темы разделены между обучением, выбором эпохи и итоговой проверкой. На 15 ранее не виденных формулировках поиск сетью поставил правильный тип первым в 11 случаях, поиск по словам — в 7. В каждом случае сравнивались три типа одного сервиса. Эти числа не характеризуют работу с реальными обращениями.

Результат проверки сохраняется в таблице `demo.reply_reviews`. Она создаётся при первом запуске экрана. В журнал событий записываются только номера заявок, действия и виды ошибок, без текстов обращений и реквизитов базы.
